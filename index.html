📋 Правила SchoolNet

1. Общие правила

  • Запрещены оскорбления, угрозы, буллинг.
  • Запрещена реклама сторонних ресурсов.
  • Запрещены заказы на незаконные услуги.
  • Запрещено разглашать личную информацию других пользователей.

2. Правила для исполнителей

  • Заказ должен быть выполнен качественно и в срок.
  • Нельзя требовать предоплату вне системы.
  • Нельзя передавать заказ третьим лицам.

3. Правила для заказчиков

  • Оплата только через SNKoin внутри системы.
  • Принимать работу или запросить доработку в течение 24 часов.
  • Нельзя требовать выполнение незаконных действий.

4. Правила для модераторов и администраторов

  • Запрещено использовать полномочия в личных целях.
  • Запрещено банить без причины.
  • Запрещено удалять заказы без объяснения причин.
  • Запрещено сливать данные пользователей.
  • При входе — включать запись экрана (система безопасности).

5. Безопасность

  • Модератор или администратор НИКОГДА не попросит ваш пароль.
  • Если кто-то просит пароль — это мошенник.
  • Немедленно сообщите через форму жалобы.

6. Санкции

  • Предупреждение — за мелкие нарушения.
  • Штраф (списание SNK) — за нарушение финансовых правил.
  • Временная блокировка — за повторные нарушения.
  • Бан — за грубые нарушения (оскорбления, угрозы, мошенничество).
